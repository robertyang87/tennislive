# 金大师选题：九站 logo 拼图（账号所有者 2026-08-14 定的方案 B）

## 为什么 ②屏 是示意图不是照片

⚠️ **不是找不到照片，是照片讲不清。** 这一屏讲的是「**集齐九站**」——
没有任何一张照片能表达一个集合被凑满，一张辛纳打球的照片只能证明
「他在打球」。这落在「示意图的触发条件是照片讲不清，不是照片找不到」
那一条上。

⚠️ 而辛纳的照片**确实也找不到**，四条路全探过，别重探：

| 路 | 结果 |
|---|---|
| Commons 高清近景 | 全是球迷周训练照（描述写着 `practice` / `ahead of`，**画面上分不出来**） |
| Commons 比赛照 | 观众席宽景，人占画面 3~5%，裁到能看清就得放大 |
| Commons CC0 竖构图 | 2019 安特卫普、静止接发、数字裁切放大痕迹肉眼可见 |
| 新华社图集 | 网页版最大 873x1023，够不着 1080x1440 |
| ATP 官网 / 赛事域名镜像 | 总站 403；罗马站返回 JS 壳页，无 `/-/media/` |

## 技术路子（已验证可行）

示意图的 SVG **可以嵌位图**，`nadal-academy` 第 2、7 屏就是这么做的：

    <image href="data:image/jpeg;base64,...." x=".." y=".." width=".." height=".."/>

所以九个 logo 各自 base64 塞进同一张 SVG。⚠️ 注意体积：卡片存 JPEG 那条
规矩是为了推送图别太大，logo 建议用 PNG（有透明底）但要压到很小，
九个加起来控制在几百 KB 以内。

## ⚠️ 权属：发布前必须人工确认

赛事 logo 是**注册商标**。我们这种「指代这九站赛事本身」的编辑用途是
最站得住的一类（不冒用、不暗示背书），但**照仓库规矩「授权照实记、
发布前由人工判断」**——每个 logo 的出处和权属要逐条写进 credits.json，
账号所有者发之前确认。

同一条也适用于已入库的 `swiatek.jpg`（WTA 官方图库，未标注开放许可）。
