# 高燃 BGM 候选清单（网球集锦/战报向）

> 搜集时间：2026-09-29；2026-09-29 更新：去掉中文曲目，全部为英文/外语曲目；每首加「建议剪切」的高燃片段。只做候选清单，不下载文件。
> 说明：抖音 `music/{id}` 独立曲目页在公开搜索中难以直接定位；以下给出已核实的可试听/可检索链接。
> YouTube 链接国内不便访问时，去 QQ 音乐 / 网易云 / 汽水音乐直接搜曲名，都有正版。
> 「建议剪切」时间为约数（凭曲式结构标注），精确卡点请以实际音频为准。

## 推荐排序

### 1. Legends Never Die — Against The Current
- 风格：2017 英雄联盟全球总决赛主题曲，流行摇滚 + 爆发力女声，"传奇永不熄灭"主题，适合冠军时刻、大场面集锦。
- 试听：https://www.youtube.com/watch?v=4Q46xYqUwZQ（Riot 官方账号上传的官方音频）
- 建议剪切：约 0:55–1:30 第一段副歌；约 2:50–3:33 最后一段副歌最燃，适合压轴。

### 2. Believer — Imagine Dragons
- 风格：重鼓点 + 爆发副歌，逆境反击感拉满，体育混剪万能燃曲。
- 试听：https://music.163.com/song?id=1338149101（网易云音乐；该 ID 对应 Imagine Dragons / Lil Wayne 合作版本）
- 建议剪切：约 0:40 预副歌 buildup 起，至约 1:35，鼓点爆发段完整收录。

### 3. Enemy — Imagine Dragons & JID
- 风格：说唱 + 摇滚的对抗感，紧张刺激，适合宿敌对决、赛前预热。
- 试听：https://www.shazam.com/zh-cn/song/1591640885/enemy-from-the-series-arcane-league-of-legends（Shazam 歌曲页可试听）
- 建议剪切：约 0:50–1:20 副歌段，对抗感最强。

### 4. Warriors — Imagine Dragons
- 风格：2014 英雄联盟世界赛主题曲，战歌属性，副歌齐唱适合大场面。
- 试听：各平台搜曲名即得（QQ / 网易云 / 汽水均有正版）
- 建议剪切：约 1:00–1:35 副歌齐唱段，战歌感拉满。

### 5. Victory — Two Steps From Hell / Thomas Bergersen
- 风格：史诗交响 + 女声合唱层层推进，适合决赛夺冠、逆转高潮段落。
- 试听：https://www.youtube.com/watch?v=DGLY5Cv8ycI（合集视频）
- 建议剪切：约 2:00–3:00 合唱与鼓组全开的高潮段。

### 6. Star Sky — Two Steps From Hell / Thomas Bergersen
- 风格：悲壮史诗、情绪起伏明显，适合人物故事、大赛总结类长视频。
- 试听：https://www.youtube.com/watch?v=DGLY5Cv8ycI（与 Victory 同一合集，约 05:20 开始）
- 建议剪切：人声进入后约 3:30–4:30，情绪落差最大的段落，适合先抑后扬的叙事。

### 7. Hall of Fame — The Script ft. will.i.am
- 风格：体育励志经典，钢琴 + 副歌爆发，适合逆袭、黑马叙事。
- 试听：各平台搜曲名即得
- 建议剪切：约 0:55–1:30 副歌段，"champion" 呼喊处卡点。

### 8. Heart of Courage — Two Steps From Hell
- 风格：史诗入门曲，鼓点 + 弦乐推进，预告片式开场好用。
- 试听：各平台搜曲名即得
- 建议剪切：约 0:30–1:30 主题旋律进入段，短小精悍适合开场。

### 9. Run Boy Run — Woodkid
- 风格：战鼓 + 铜管 + 史诗人声吟唱，气势压迫感强，体育广告常用，适合追分、反扑段落。
- 试听：https://www.bandmine.com/yaboirone/videos/2/lmc21V-zBq0（官方 MV 页面）
- 建议剪切：约 1:00–1:40 "Run boy run" 副歌段，战鼓最密处。

### 10. Remember the Name — Fort Minor
- 风格：Mike Shinoda（Linkin Park）嘻哈企划，"百分之十运气+百分之百记住这个名字"，说唱卡点适合球员个人集锦。
- 试听：https://www.youtube.com/watch?v=VDvr08sCPOc（官方 MV）
- 建议剪切：约 0:55–1:25 副歌段，"ten percent luck" 花式报数处卡点效果最好。
