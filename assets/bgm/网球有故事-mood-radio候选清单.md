# 网球有故事 · mood radio 候选清单

> 搜集时间：2026-09-29。全部为英文/外语纯音乐或氛围系曲目，适合人物叙事、故事类视频做铺底 BGM（不抢解说）。
> 说明：YouTube 链接国内不便访问时，去 QQ 音乐 / 网易云 / 汽水音乐直接搜曲名，都有正版。
> 「建议截取」时间为约数（凭曲式结构标注），精确卡点请以实际音频为准。

## 推荐排序

### 1. Tycho — Awake
- 风格：氛围电子 / 后摇，吉他 + 合成器层层铺陈，90bpm 左右的推进感，经典"公路片"质感，叙事铺底万能。
- 试听：https://www.bandmine.com/tychojames/videos/2/zO_h1dKAvc4（官方 MV 页面）
- 建议截取：约 2:30–3:30，主旋律完全展开、鼓组进来的段落，情绪最满。

### 2. Bonobo — Kerala
- 风格：Downtempo 电子，细碎鼓点 + 迷幻合成器，高级感强，适合人物特写、慢镜头段落。
- 试听：https://www.bandmine.com/sibonobo/videos/2/S0Q4gqBUs7c（官方音频页面）
- 建议截取：约 1:30 起的 drop 后段，律动最完整。

### 3. Emancipator — Soon It Will Be Cold Enough To Build Fires
- 风格：Trip-hop / 未来爵士，小提琴 + lo-fi 鼓点，雨夜氛围，独行侠式人物故事绝配。
- 试听：https://www.youtube.com/watch?v=QRgPIbSX1mg
- 正版购买（$1 单曲下载）：https://emancipator.bandcamp.com/track/soon-it-will-be-cold-enough-to-build-fires?action=download
- 建议截取：整曲氛围均匀（3:00），0:00 起直接铺底即可，小提琴段（约 1:00–2:00）情绪最浓。

### 4. Khruangbin — Maria También
- 风格：迷幻放克 / 泰式灵魂乐，贝斯 groove + 吉他，复古胶片感，适合怀旧向、老将故事。
- 试听：https://www.youtube.com/watch?v=7hlGqj3ImQI（官方 MV）
- 建议截取：约 1:45 吉他 solo 段；Shazam 数据显示 2:15 附近是全曲最抓耳的 hook。

### 5. Nujabes — Reflection Eternal
- 风格：爵士嘻哈（Jazz-hop）开山之作，钢琴 loop + 爵士鼓，lo-fi 鼻祖，沉静叙事的首选。
- 试听：各平台搜曲名即得
- 建议截取：前 2 分钟钢琴主段，干净无歌词，解说位最友好。

### 6. DJ Okawari — Luv Letter
- 风格：日式器乐嘻哈，钢琴 + 弦乐，温柔但有推进，适合温情向、师徒/家庭故事。
- 试听：各平台搜曲名即得
- 建议截取：约 1:00–2:30 钢琴与弦乐齐奏段。

### 7. Tomppabeats — Monday Loop
- 风格：经典 lo-fi hip hop，磁带质感鼓组 + 柔和采样，"lofi girl"式电台味最正的一首。
- 试听：各平台搜曲名即得
- 建议截取：整曲循环结构，任意 2 分钟切片都可无缝铺底。

### 8. ODESZA — Sun Models
- 风格：Chill 电子，人声切片 + 宽广合成器，黎明感，适合大赛总结、赛季回顾类长视频。
- 试听：各平台搜曲名即得
- 建议截取：约 1:00 起副歌段，情绪扬起来的部分。
