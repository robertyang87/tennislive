# WTA 首次蒙版扫描并行耗时

2026-10-14：在 #1245 的分段缓存之上，首次没有缓存的 WTA 多回合蒙版扫描最多用两个线程并行。整组命中仍直接走原有路径；局部修订继续只重扫输入改变的回合。每个任务有独立的段落对象和输出目录，完整报告按 spec 顺序组装。

并发取 CPU 数、进程 affinity、cgroup CPU 配额、内存上限与调用者上限的最小值，最多两路。内存估算考虑帧率、窗口长度、搜索带高度、原始 RGB 捕获的双份临时字节和逐帧几何开销，至少按每路 2 GiB、父进程 1 GiB 留预算；长窗口或资源不足时退回串行。`TENNISLIVE_SCOREBOARD_MASK_WORKERS=1` 可显式使用串行。

缓存提交及清理串行执行，防止多个任务同时替换/淘汰缓存条目。源片字节、算法和依赖、FFV1 蒙版哈希、所有帧的时钟、数量、尺寸与复制后的哈希检查均保留。任务失败时等待其余线程结束，清理临时目录，不写完整报告、不修改调用者的段落几何；错误继续阻断制作。单段已成功完成的合法缓存可用于后续重试。

## 素材实测

使用本次郑钦文—斯维托丽娜北京四分之一决赛的同一源片，SHA256 `da97c5eafb072aa2087e1cee2d893a2c1ea687ac8ef941373e9ccc76553f1d3d`。6 个窗口、3,840 帧，独立空缓存测量，环境 CPU 配额 4 核、内存上限 16 GiB。

| 蒙版步骤 | 实测秒数 |
|---|---:|
| 1 路串行，空缓存 | 35.722 |
| 2 路并行，空缓存 | 23.561 |
| 2 路并行复测，另一份空缓存 | 24.977 |
| 完全相同的整组缓存命中 | 1.155 |
| 只修改一个窗口，5 段复用、1 段重扫 | 5.586 |

首轮对比节省 **12.161 秒，约 34%**。第二次并行复测期间同时运行相关测试。两次并行生成的所有 3,840 个灰度蒙版解码帧、原生几何报告与串行生成逐项一致；热缓存文件字节完全相同。局部修改时，5 个未改窗口的文件字节保持一致。正式 spec、成片和发布状态未改动。

以上只测比分板蒙版步骤，不代表端到端出片缩短 34%，也不保证所有机器收益相同。其他比分板沿用现有路径。

证据：[逐段解码哈希与测量数据](benchmarks/wta-parallel-mask-scan-2026-10-14.json)、[完整运行日志](benchmarks/wta-parallel-mask-scan-2026-10-14.log)。验证包括乱序完成仍按 spec 排序、任一任务失败不产生完整报告、CPU/affinity/内存/长窗口预算，以及原有缓存失效、损坏修复和帧时钟检查。
