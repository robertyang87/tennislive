# 赛场之上：剪辑手法 + 叙事逻辑 参考模板

2026-08-17 从成品片子里提炼（swiatek-kostyuk / shelton-tien / baez-dimitrov /
zhang-sabalenka / hijikata-monfils）。账号所有者要求：文案要「有球员信息背景、
有趣生动、引人入胜、结合比分和视频内容」，剪辑手法参考已有成品。

## 一、叙事骨架：固定九屏（顺序是叙事顺序，时间戳乱序）

```
① 冷开场  最抓人的那一分（赛点/逆转/爆冷瞬间），无旁白只留现场声
② 落点    结果 + 最硬的数字反差（"决胜盘四比一领先，连丢最后五局"）
③ 坐标    北京时间 + 赛事 + 轮次
④ 身份    种子/排名/年龄/国籍（一句带过，别展开）
⑤ 首盘    走势（beat 1）
⑥ 中段    转折（beat 2，破发/保发/抢七）
⑦ 结局    赛点/锁定比分（beat 3）
⑧ 场外    切口（H2H 复仇 / 纪录 / 告别 / 金句），一句带过
⑨ 收尾    一问（互动，"这样的球你见过几次？"）
```

⚠️ **关键手法：时间戳乱序**。第①屏是 197s（赛点），第③屏跳回 10s（开场），
再按比赛时间顺序走到结尾。**先给结果，再倒叙**。这是短视频抓人的第一手段。

## 二、旁白的写法（文案质量的四个来源）

### 1. 有球员背景（不纯报比分）
- baez-dimitrov：「三十五岁的迪米特洛夫」「世界第一百三十八持外卡」
  「他正是在这块场地拿过冠军（2017）」——**年龄、排名、历史**都是背景
- hijikata-monfils：「三十九岁的孟菲尔斯，第十四次来」「再过十八天满四十岁」
  「这个赛季打完，他就不打了」「网前，两个人抱了一下，全场起立」——**告别叙事**

### 2. 有趣生动（数字反差 + 悬念）
- baez：「全场一百五十三分，他拿了七十九分，比巴埃斯多五分。**多拿五分的那个人输了**」
- zhang-sabalenka：「世界第一双误四个，却赢了」「全场张帅零个双误，非受迫失误只有一个」
- hijikata：「决胜盘第二局有五个局点，**一个都没保住**」

### 3. 引人入胜（每句一个悬念，层层推进）
- baez 决胜盘五连局，每局单独成段，像连续剧：「一度四比一领先」→「连丢四局」→「五比四」→「多拿五分却输了」
- zhang：「三十比零领先，这一局本该是她的」→「然后连丢四分」

### 4. 结合比分和画面（旁白讲的事，画面正好是那一分）
- 每一段旁白挂到比分板显示对应比分的那个窗口（见 scoreboard-alignment.md）
- 无旁白的段（①冷开场、现场声段）留给「赛点落地、庆祝、网前握手」这些情绪画面

## 三、收尾一问（互动，不是空话）

| 片子 | 收尾 |
|---|---|
| baez | 「决胜盘四比一领先还能输掉，这样的球你见过几次？」 |
| zhang | 「差的是一分——你觉得差在哪儿？」 |
| hijikata | 「你会记得他的哪一场球？」 |
| shelton | 「决赛，等着他的是中岛——一场全美国德比」 |
| swiatek | 「这份状态，她还能带多远？」 |

⚠️ 禁「还能走多远」这种空话（CLAUDE.md 记过）。收尾要落在**这一场球的具体
悬念**上，不是泛泛的展望。

## 四、文案的素材来源（每个事实都要有出处）

| 素材 | 来源 | 例子 |
|---|---|---|
| 比分/转折 | 逐分数据（fetch_match_pbp） | 「四次发球局全丢」「三个赛点救回两个」 |
| 排名/年龄/国籍 | lookup_player_meta | 「世界第 138 持外卡」「35 岁」 |
| H2H/复仇 | match_stat_hooks.h2h_candidate | 「赛前交手两次，全是他赢」 |
| 纪录/背景 | 赛事官方稿/编辑稿 | 「1992 年后第一次三个美国人同时进半决赛」 |
| 金句 | 赛后采访原声/转写 | 「我现在的状态完全不一样了」 |
| 画面 | 缩略图墙 + 比分板 | 「网前，两个人抱了一下」 |

## 五、剪辑手法要点

1. **冷开场不配旁白**：第①屏赛点/庆祝，留现场声（观众欢呼、击球声），
   让情绪自己说话。
2. **结果先说**：第②屏就把「谁赢、比分、最硬的数字」甩出来，再倒叙。
3. **每句旁白 < 50 字**：一条一个事实，不堆叠。
4. **段尾落在死球后**：旁白说完，画面正好这一分打完（死球时刻对齐）。
5. **场外切口只一句**：H2H/纪录/告别这类，点到为止，不展开重讲
   （CLAUDE.md「同一栏目内不重讲」）。
