# 「历史今天」和「昨日好球」：现状与改造需求

> 这两个不在 `docs/columns.md` 的三栏目表里——那张表管的是**解说视频**的栏目
> （`explainer.py` 的 `COLUMNS`）。这两个是图文线和视频线上另外两条独立产品，
> 各有各的链路、各有各的毛病。
>
> 全部结论对着**产物或代码行**说话。需求部分每条都带判据（可落成测试的那句），
> 没有"应该会变好"。

|---|---|---|
| 跑在哪 | `daily.yml` 知识帖槽位的一个候选 | 独立工作流，一天 6 班 |

## 二、历史今天

### 现状：它不是栏目，是「网球有故事」里的一个日期开关

| 查什么 | 查到的 | 证据 |
|---|---|---|
| 参选规则 | 只在 slug 尾号 == 当天 MMDD 时参选，得 **1 分** | `tournament_story.py:2454-2458` |
| 谁能挤掉它 | 球员特写 **3**、赛事档案 **2** | 同上 2445-2466 |
| 库存 | **4 条**：`otd-0725/0803/0820/0909` | 全库 grep |
| 发过几次 | **0 次** | `data/story_state.json` 九个 slug，无一 `otd-` |
| 公开名字 | **「网球有故事」** | `knowledge.py:66` 写死 `📖{day}网球有故事｜` |

四条要点，按严重程度：

**1. 正日子也没轮到它，而且证据被自己冲掉了。**
7/25 是 `otd-0725` 的正日子。**四道闸门离线复算全部通过**：图在仓库里、
日期匹配、不在冷却期、`kind=trivia` 得分 1（高于冷知识的 0）。当天发的却是
`golden-slam`（`output/2026-07-25/knowledge/story.json`）。

拒因机制其实**是有的**——`knowledge.py:617` 的 `rejected_candidates` 会连同
`visual_preflight_rejections` 写进 `visual_sources.json`。但 7/25 那份是 **`[]`**，
说明落盘的这一次它连候选都不是。两条机制合起来解释了这个形状：

- `daily.yml:226-228` 同日重跑 `rm -rf "$OUT_DIR/knowledge"`——**上一班的拒因记录
  连同目录一起没了**
- `tournament_story.py:2434-2437` 的 pinned 分支让重跑直接复用当天已定的故事，
  第二班走的是另一条路径、一次拒绝都不会发生，落盘的自然是 `[]`

所以真正的毛病不是"没有诊断"，是**诊断被同日重跑冲掉了，而且只记谁赢、不记谁参选**。
它看起来像"今天没有历史今天"，实际是"有，但证据被覆盖了"。

**2. 全年最强的那一条，配的是错的球场。**

| slug | 讲的是 | 配的图 | 对不对 |
|---|---|---|---|
| `otd-0725` | 2021 阿尔卡拉斯乌马格首冠 | `umag-goran-ivanisevic-stadium.jpg` | ✅ |
| **`otd-0803`** | **2024 郑钦文巴黎奥运金** | **`canada-national-bank-open-stadium.jpg`** | ❌ **蒙特利尔** |
| `otd-0820` | 2023 辛辛那提决赛 | `cincinnati-lindner-tennis-center.jpg` | ✅ |
| `otd-0909` | 2023 高芙美网夺冠 | `usopen-arthur-ashe-stadium.jpg` | ✅ |

这就是 CLAUDE.md 里「讲法网配温网草地」那条错误的翻版，而且正好落在 ⭐⭐⭐ 的
那一条上，**7 天后就要用**。顺带一条系统性问题：现有 4 条**全是场馆空镜**，
按「精准之外还要有冲击力」的判据，场馆照属于"能用但没劲"。

**3. 库存 4 天 / 365 天 = 1.1%，而弹药早就备好了。**
`content-calendar.md` 第一节有 13 个已联网核实、带信源的锚点。那份文档自己
第 94 行就写着"补进系统 on-this-day 模块，到点自动触发"——这一步没做。

**4. 它是账号唯一验证过的爆款形态，但爆的那条不是它生成的。**
`weekly-report.md:101`：07-21 21:35「球星叙事·历史今天」，阅读率 **40.6%**、
42 赞占全周点赞 86%；同周纯赛程赛果头条只有 4.1%–11.7%。而那天知识帖系统发的是
`hawkeye`（18:10，2 赞），仓库里找不到 21:35 那条的产物。
**手做的炸了，自动的一次都没上过场。**

### 需求

**先定一件事：不开第四个栏目。** `docs/columns.md` 已完整论证过——试了
`First Serve` / `Second Serve` / `人物志` 全撤了，理由是"栏目多了读者记不住"。
解说视频的三栏目**一个字不动**；下面 R4 说的是图文线的系列标签，不是第四个栏目。

#### R1 · 命中当日就该压过所有人 ✅ 已落地

拿 7/25 那天的真实条件复算过（仓库里的 `story_state.json` 至今还带着
`"golden-slam": "2026-07-25"`，正是当时把它挡掉的那个 pinned 条件）：
**改前 `golden-slam` 第一、`otd-0725` 第二**——排第二意味着第一名一次就成稿了，
它根本没被试过，所以 `rejected_candidates` 是空的；**改后 `otd-0725` 第一**。

| | |
|---|---|
| 现状 | `otd-*` 命中当日得 1，球员特写得 3 |
| 改成 | 命中当日得 **4**（全场最高），且**不进冷却期判断**——一年一次，不存在"最近讲过" |
| 代码 | `tournament_story.py:2454-2458`、2467 |
| 判据 | `test_历史今天在正日子压过所有其他候选`：构造一个当天有夺冠球员热度的 digest，断言 `tournament_story_candidates(digest)[0].slug` 是那天的 `otd-*` |
| 风险 | 纪念日撞上重大赛果时会把当天的球员特写挤到第二。这是有意的：球员明天还有，纪念日一年一次 |

#### R2 · 别让同日重跑冲掉诊断，并把排序本身记下来 ✅ 已落地

落在 `output/YYYY-MM-DD/story_selection.json`（**当日目录，不在 `knowledge/` 里**），
按班次追加。每条故事都带齐同一套字段——落选的 `rank`/`score` 留 `null` 但 `reason`
非空，读它的 jq 不必为"这个键在不在"分两种写法。

| | |
|---|---|
| 现状 | 拒因机制有（`knowledge.py:617` → `visual_sources.json`），但同日重跑 `rm -rf knowledge/` 会连记录一起删；而且它只记"试了谁"，不记"谁参选、各得几分" |
| 改成 ① | 拒因**按班次追加**、不被同日重跑清空——落在 `knowledge/` 外面，或改成带班次戳的追加写 |
| 改成 ② | 落 `story_selection.json`：`tournament_story_candidates()` 返回的**排序后完整列表 + 每条得分 + 落选原因** |
| 追加 | `daily.yml` 里：当天有 `otd-*` 参选但最终成稿不是它时，打 `::warning` |
| 判据 | `test_同日重跑不会冲掉上一班的候选诊断`、`test_知识帖要记下排序后的完整候选和得分` |
| 为什么 | 没有这条，R1 做完了也没法证明它生效——7/25 就是这么丢的，而且丢得连痕迹都没留 |

#### R3 · 补库存，但不补满 365 天

按批次补，每批的验收都在图上，不在条数上。

| 批次 | 锚点 | 距今 |
|---|---|---|
| **批次 1（本周）** | 8/2 张之臻·王欣瑜混双银牌、**8/3 郑钦文奥运金 ⭐⭐⭐**（含**换图**）、8/16 辛纳生日 | 6 / 7 / 20 天 |
| 批次 2（美网前） | 9/6 萨巴卫冕、9/7 萨巴首冠、9/8 辛纳、9/10 斯瓦、**9/11 阿卡 ⭐⭐⭐**、9/19 李娜退役 | 41–54 天 |
| 批次 3（亚洲赛季 + 淡季） | 10/8 郑钦文生日、9 月末张之臻亚运金；12 月无巡回赛，用常青中国故事兜底 | — |

**每条的成稿标准**（这是验收，不是建议）：

- 图必须是**那一年、那个人、在球场上**的画面——不是领奖照、不是训练照、
  不是发布会、不是场馆空镜
- **拿不到当年实拍就不建这一条**，不用近似照片顶替（大威那条的教训）
- 画面上写年份；出处进 `assets/**/credits.json`
- 横幅原图先裁成 3:4 再入库，人居中、左右留够
- 没有锚点的日子**不硬凑**——凑出来的就是资料照级别的内容，宁可回 `网球有故事`

| | |
|---|---|
| 判据 | `test_历史今天的图片要和它讲的赛事对得上`：每条 `otd-*` 的 `image` 文件名 / `credits.json` 记录必须命中该条声明的赛事关键词（`otd-0803` 现在会红） |
| 追加判据 | `test_历史今天的slug和它写的日期一致`：`slug` 尾号 == `location` 里那个"X 月 X 日" |

#### R4 · 让读者看见这个承诺

| | |
|---|---|
| 现状 | `knowledge.py:66` 写死 `📖{day}网球有故事｜`，OTD 也印这个 |
| 改成 | `otd-*` 用 `📅{day}历史上的今天｜` |
| 判据 | `test_历史今天用自己的标题前缀`：断言 otd 故事的小红书标题不含「网球有故事」 |
| 说明 | 这不是开第四个栏目。卡片小标和 chips 早就写着「历史上的今天」了，**只是标题没跟上**——而读者只看标题。承诺印不出来，这个栏目对外就不存在 |

#### R5 · 排期与备料

- **发布窗口固定 20:00–21:30**：爆的那条是 21:35 发的，周报的决策
  （`weekly-report.md:136-145`）也已写明头条从上午改晚间。历史今天和每日速报
  （早上）天然错开，正好占这个窗口
- **产物就绪时间 ≤ 19:30**：知识帖现在的补产班次是 15:07 / 18:23 北京时间，够用；
  但 OTD 命中当日要能触发一次**专属补产**，不能因为当天知识帖已经成稿就跳过
- **⭐⭐⭐ 锚点提前 7 天备料**：图先探、先入库、**先人工 `Read` 看过**，
  不留到当天现搜。8/3 从今天起就该开始
- **选题优先级按已验证的排**：中国球星 > 全球顶星 > 赛事

## 三、昨日好球

### 现状：机器很稳，内容很薄

机器侧该有的都有：六班次（北京 06/08/10/12/16/21）、ATP 与 WTA 独立选片独立推送、
已成的巡回赛后续班次跳过、跳过时 `skip.json` 落盘每一路 resolver 试了什么。

命中明细（全部有产物为证）：

| 日期 | ATP | WTA | 备注 |
|---|---|---|---|
| 07-24 | ✅ Hot Shot | ✅ Hot Shot | |
| 07-25 | — | — | **整个 `yesterday-point/` 目录都不存在**，连 skip.json 都没有 |
| 07-26 | ❌ | ❌ | skip.json 正常 |
| 07-27 | ✅ Hot Shot | ❌ | |

内容侧四个问题：

**1. 一条无名之辈的 Hot Shot 永远赢过一条中国球员的官方集锦。**
`daily_point.py:547-556` 里 `consensus_rank × 1000` 是绝对压制项，
rank-1（Hot Shot）先天比 rank-0（官方集锦）高 1000 分，而中国球员只加 **30**。
07-27 发出去的是范阿舍 vs 加斯东，埃斯托利尔半决赛。
**周报的结论是"中国球星是唯一验证过能爆的角度"，选片逻辑和它反着。**

**2. 文案正好是周报判定失效的那一类。** 今天发出去的全文：

```
🎾7.27 昨日好球｜穿越球，太顶了

全场高能：一记穿越球。
范阿舍 vs 加斯东｜埃斯托利尔公开赛，赛果 范阿舍 6-4 7-5。
```

一句模板感叹、一句事实、一行标签。它和周报里阅读率 4.1% 的『22:30出战』
是同一个形状——**报事实，不给理由**。
而更有戏的料代码里已经有：`_official_match_hook()`（`daily_point.py:1348-1362`）
能从官方描述抠出「挽救赛点惊险过关」「先丢一盘完成逆转」「N 分钟速战速决」，
但它只在**没认出击球名词时**才被调用（1407 行的 `else`）——
认出"穿越球"反而把那句挤掉了。

**3. 字幕只讲对阵和比分。** 成片两条（`yesterday-point.ass`），
第一条 18 秒是「这一分，值得暂停｜范阿舍 vs 加斯东」。
**那 18 秒是最贵的，却没说这一分为什么值得看。** 静音刷是默认状态。

**4. 四个名字。**

| 出现的地方 | 印的字 |
|---|---|
| `docs/yesterday-point.md:3` | 这一分，值回放 |
| `push.html` 栏目标签 | 这一分，值得回放 |
| 成片第一条字幕 | 这一分，值得暂停 |
| 小红书标题 / commit | 昨日好球 |

**5. 零数据。** 这条线 07-24 开始跑，`weekly-report.md` 记到 07-22，
至今一条没进过周报，playbook §7.1 的必录字段一个没录。

### 需求

**先定位：它不该是"每天一条好球"，是"能讲出故事的那一条好球"。**
4 天成 3 个的命中率不是缺陷，是天然质量闸。**不要为了填坑再降门槛**——
`review-2026-07-25.md` 已经放宽过一轮（接受 highlights、放行 rank-2、加两个班次），
再放就该发陌生人的普通球了。**空一天比发一条没人看的强。**

#### R12 · 文案要用上我们自己手里的赛果

2026-07-27 实际发出去的那条把这个缺口暴露得很清楚：

| | |
|---|---|
| 发的 | 范阿舍 vs 加斯东，埃斯托利尔**半决赛**穿越球，文案写「赛果 范阿舍 6-4 7-5」 |
| 同一份 digest 里还有 | 范阿舍昨天**拿了埃斯托利尔冠军**，决赛 6-4 4-6 **7-5** 三盘赢下布洛克斯 |
| 读者看到的 | 一个陌生名字打了场半决赛 |
