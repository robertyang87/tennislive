# 赛场之上原声与检查策略

2026-10-13，账号所有者要求把声音响度处理和校验拿掉。普通赛场之上现在默认保留现场击球、观众和转播解说的原有大小。中文配音叠加时不压低现场声，不添加压缩或响度归一化；原有镜头之间的音画溶解保留。

新普通配置不用额外填写音量开关。此前已经使用的配置仍可保留这行：

```json
{"preserve_source_audio": true}
```

普通配置不能同时设置音乐、bed、mute、替换音轨或变速；实际渲染入口会在下载、TTS和编码之前拒绝冲突。已有明确授权的特殊音效/替换模式及其他产线仍按自己的合同处理。

普通制作已移除源片峰值和逐块响度扫描、渲染前静音预测、语音尾部响度测量、成片逐秒RMS和自然弱声/源声增益波形比对。也不再只为响度预测重复下载probe资料，低声不触发这类返工。

保留实际配音读音与时长、完整原声语句、字幕时序、画布和剧情检查。成片QC通过一次ffprobe检查实际音视频流是否合法、时长是否为有限正数，以及音轨尾端是否跟上画面；仍绑定电影、ASS和spec哈希，推送仍要求唯一账本和真实PushPlus回执。新凭证将响度检查记为`removed_by_owner`。

新渲染记录`source_audio_policy: unity_no_loudness_v1`。旧电影的混音结果由当时实际产物决定；已发布影片和推送记录保持原状，不为这次规则更新重渲或重推。
