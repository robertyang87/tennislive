# 比分板上方的分段字幕位置

原生 `segments[].subtitle_bottom_windows` 支持同一段内逐句设置字幕底边距，时间按段内成片秒数，不包含封面偏移。默认位置沿用 `subtitle_bottom`，窗口外保持默认；窗口须有序、不重叠、处于段内，底边距为96–1344的整数。字幕跨越两种位置的边界会报错，不自动拆句。

```json
{
  "subtitle_bottom": 360,
  "subtitle_bottom_windows": [[0.19, 2.51, 306]],
  "quote": [{"at": 0.19, "end": 2.51, "text": "Lovely.\n漂亮"}]
}
```

本期WTA实拍中，普通小比分板用306、带提示条用360，相关居中赛果图字幕用480；实际中文下缘距小板或ROUND1标题约30像素。这是本源的校准结果，其他转播须查看原生画面与真实比分蒙版后确定。不要按赛事名猜布局，也不要统一下移后遮住提示条。

先确定完整字幕句子的时间范围，再按同源逐帧蒙版检查这个范围是否含提示条。居中大比分图应另看实际完整帧，因为它沿用源图、没有小板回贴蒙版。变化会进入渲染输入投影，旧影片凭证会拒绝新的字幕位置。

2026-10-12账号所有者补充：不建议改现场原声大小。本期撤回为满足响度判据而加的6dB，保留原制作版音轨；字幕修改不应顺带改动原声响度。低声段应核验真实源声、完整词尾与实际混音，不为过检查强行增益或归一化。
