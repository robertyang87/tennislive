## 0. 一句话定位

> 别人给你看好球，我们告诉你**这场球在哪一分改变、这个人为什么走到这里、
> 他自己怎么说**。（`column-differentiation-design.md`）

差异化的根不是素材（我们没版权），是素材之上的**逐分数据 + 全称断言事实核验 +
双语第一手 + 评论号立场**。文案的价值在于把这四样织进一条「说的是这个人、
不是这个比分」的叙事里。**所有背景信息都必须有出处，所有数字都必须能查。**

### 1.1 每个背景怎么用（写入文案的规矩）

- **身份类（排名/年龄/国籍/种子）一句带过，别展开**：海报名条已经印着排名和国籍，
  旁白再写一遍是白占字数。CLAUDE.md 判据：「这一屏在讲过程还是讲身份」——身份
  海报别处印着，钩子写的是**过程**（几比几、救几个赛点）。
- **来路类（伤停/保护排名/上轮战果）只给一句、带数字、贴这场球**：例「去年他脚伤
  停了五个月，排名掉到两百七十，这一站靠保护排名进的正赛」（`shang-rublev` seg6）。
  判据是「看不懂这场球所必需的来路 → 一句带过」；「上一条铺开讲过的 → 一个字别碰」
  （`_no_repeat`）。
- **纪录/里程碑必须走全称断言双源**（`_claims`）：写「生涯首冠」要能查到历史计数，
  写「史上第几次」要两个源。P1 历史状态库上线前，「生涯首冠/首次进入某轮/成功卫冕/
  终结 N 连败」默认禁用，除非证据包含对应计数。
- **金句原样用，别改写数字**：给了背景里的数字，用了就原样，不润色出新的。
- **热点/常青角度是「场外切口」不是「正文」**：只在 human_context 一句带过，
  不抢主线（这场球的走势）。

## 2. 文案写作要求

### 2.1 「赛场之上」内容合同（`editorial` 五件套，79/79 条新格式完全一致）

```
editorial:
  mode: "match_review"
  question:     全片要回答的一个问题（具体到一场球的数字/局面 + 悬念）
  thesis:       一句话结论（常反直觉）+ 2-4 句带数字论证 + 落比分/结果
  beats:        [前段走势 / 中段转折 / 结局回应] 三条
  human_context: { angle(场外切口), facts(逐条可查), sources(URL) }
```

- **question 规律**：具体到一场球的数字/局面 + 「怎么/为什么」+ 悬念。数字必带两个
  （「两小时四十七分 + 七个赛点」「少七个 + 少两个」）。
- **thesis 规律**：先给一句话结论，常反直觉——「输的那盘输得彻底所以赢了」
  （`boulter-volynets`）、「扛住了对手，没扛住身体」（`djokovic-tirante`）。
- **beats**：恒 3 条，前段/中段/结局，是旁白的骨架（对应 9 屏的 ⑤⑥⑦）。
- **human_context.angle**：写「这场球在故事线上卡在哪儿」——连败的结束、里程碑后的
  第一周、老将的告别线、生涯首次交手；**必带可查出处**（转播原话、WTA 官方用词、
  具体日期），不写套话。

### 2.2 钩子（cover.hook）：上句挖坑、下句翻转

- **格式**：两行，每行 **≤10 字符**（solo 版式硬闸 `HOOK_MAX_CHARS = 940 // 94 = 10`）。
- **结构**：「上句先给坑、下句给翻转，**顺序不能反**」。四例被反复引用：

  ```
  连输普汀塞娃七次 / 三十七岁，她赢了
  两次只差一个发球局 / 两次都没保住
  六个破发点全丢 / 他等到了第七个
  决胜盘二比五落后，五个赛点 / 他一个没给，掀翻世界第十六
  ```

- **两条铁律**（来自 `_hook_why`）：① 讲**过程**（几比几、救几个赛点），不讲**身份**
  （排名/年龄/冠军数——海报赛果行已印着）；② 「五个赛点」这类数必须**逐分核过**
  才能写进钩子。
- 判据（CLAUDE.md）：「钩子要有剧情的跌宕，不是把两个身份摆在一起」——这条**没有
  测试，是故意的**，机械挡不住（试过「必须含一个非排名的数」，恰好被「伤停五个月」
  绕过）。

### 2.3 旁白（segments narration）

- **每句 ≤ 50 字，一条一个事实，不堆叠**（`draft_spec.py` SYSTEM 硬规矩）。
- **实证分布**（1429 段）：中位 **28 字**、均值 30.6、P90 49、最短 3 字（「抢七。」）、
  最长 167 字（决赛长段，靠 3-5 个短句堆节奏，无 60+ 字不加标点的句子）。
- **每条片子旁白段数中位 12 段**（min 5 / max 38）。
- **最短那段是「悬念的铡刀」**：报一个转折点，不给评论（「抢七。」「第四个赛点。」）。
- **四种质量来源**（`reel-narrative-template.md`）：
  1. **有球员背景**（不纯报比分）：年龄/排名/历史/告别——「三十五岁的迪米特洛夫」
     「再过十八天满四十岁」「这个赛季打完他就不打了」。
  2. **有趣生动**（数字反差）：「多拿五分的那个人输了」「五个局点一个都没保住」
     「世界第一双误四个，却赢了」。
  3. **引人入胜**（悬念层层推进）：「一度四比一领先」→「连丢四局」→「多拿五分却输了」。
  4. **结合比分和画面**：旁白讲的事，画面正好是那一分（逐分对齐，见 §3.2）。

### 2.4 收尾一问（互动，不是空话）

- 落在**这一场球的具体悬念**上，不是泛泛展望。禁「还能走多远」这种空话。
- 例句：「决胜盘四比一领先还能输掉，这样的球你见过几次？」（baez-dimitrov）
  「差的是一分——你觉得差在哪儿？」（zhang-sabalenka）「你会记得他的哪一场球？」
  （hijikata-monfils）。
- interview 版（`takeaway.close.ask`）：「拼到极限却没能拿下冠军，值得吗？」
  「陪你打球的人，你谢过他吗？」
- 问句只开一扇门，不替观众收尾。

### 2.5 推送（push）与小红书正文

**push**（`push_reel.py`）：
- `summary`（推送标题，≤20 字位）+ `lead`（正文第一段）；`matchup/score/event` 不写，
  由封面算——「一个数写两处必分叉」。
- 标题卡整句（`xhs_title_len`：全角记 1、半角记 0.5），讲不完的半句交给 `--lead`。

**小红书正文**（`.xhs.txt`，146 个样本结构一致）：
```
[悬念首行]
📍赛事坐标
🎾 比分｜用时
[正文：reel 叙事段 + 「· 」数据列表；interview ①②③ 分段 + 中英金句]
[结尾问句：「评论区聊聊/评论区站队」]
#标签（恒在最后一行，3-5 个，主角/赛事词优先，禁给正文未出现的球员蹭标签）
```
- 开头第一行是悬念句或金句句（46 个文件开头各不同）；标签 median 1 行。
- 完整比分放图片/坐标行，正文不逐字复述；「三条硬事实块」（过程/背景/里程碑编号
  列出）是已被采纳的正文形态（short-video-benchmark §1.6）。

### 2.6 事实底线（全部可落测试）

- 只写给到的素材里有的事实，不编造比分、不编造球员说的话。
- 排名必须和 `matchup`/`versus` 登记的一致（「排名有两个出处就必然分叉」）。
- 种子序号不是排名。
- 纪录走全称断言双源；「生涯首冠」等表述证据不足时降级为「球员 + 结果 + 轮次」句
  （「降级不是失败」）。
- 引用源片的话，落笔前 grep 转写确认；grep 不到就别写那一句。

## 3. 剪辑流程（含逐分对齐）

### 3.1 九屏叙事骨架（顺序是叙事顺序，时间戳乱序）

```
① 冷开场  最抓人的那一分（赛点/逆转/爆冷），无旁白只留现场声
② 落点    结果 + 最硬的数字反差
③ 坐标    北京时间 + 赛事 + 轮次
④ 身份    种子/排名/年龄/国籍（一句带过）
⑤ 首盘    走势（beat 1）
⑥ 中段    转折（beat 2，破发/保发/抢七）
⑦ 结局    赛点/锁定比分（beat 3）
⑧ 场外    切口（H2H 复仇 / 纪录 / 告别 / 金句），一句带过
⑨ 收尾    一问
```

- **关键手法：时间戳乱序**——先给结果，再倒叙（短视频抓人第一手段）。
- 开场三格（0-3 秒定生死）：① 最强一格画面（不配旁白）→ ② 一句话甩落点/最大反差
  → ③ 坐标。违反它的那条正是完播 2.34% 的那条。
- 剪辑手法清单（变速 `seg.speed` 0.4~2.5，<1 慢放、>1 快放；回放 = 同一窗口两段、溶解、死球后切、
  现场声+闪避混音、字卡 `inset` 贴角、快放 `seg.speed` 1~2.5）；**背景音乐走
  `spec.music`**——2026-08-27 之前这条线明令不加，账号所有者当天点名「还有背景音乐」
  之后翻面。它是铺在现场声底下的一层，和现场声一起被旁白闪避，要量出来低 8 dB，
  `silent_source` 的片子一律不许配（详见 `docs/columns.md`）。

### 3.2 逐分 ↔ 比分板对齐（旁白挂载的核心，`scoreboard-alignment.md`）

- **原则：逐分数据 = 内容（第几分、谁破发、赛点），比分板 = 定位（画面里这一刻
  是几比几）**。旁白讲「赛点」，画面必须正好是比分板显示赛点那一刻。
- **实现链**：`read_scoreboard.py`（MiniMax M3 读**全帧** `contact_*.jpg`，不读
  预裁剪的 `score_*.jpg`）→ 逐分数据算出关键分（赛点/破发点/盘点）→ 在比分板
  读出的时间戳上对齐 → 旁白窗口挂在对应秒。
- 为什么不能直接拿 296 个死球跳变凑 66 分：翻牌动画 + 慢放噪声，5s 阈值合并到
  120 也够不到 66。**所以是「用逐分数据当内容、用比分板定位」，不是「从比分板
  反推逐分」**。

### 3.3 慢放/回放/字卡的用法

- 慢放：`start/end` 仍是源片窗口；成片占 `(end-start)/speed` 秒，旁白预算按成片
  时长算（`--dry-run` 自动换算）；`quote` 的 `at` 是成片段内秒数；**只认慢放，
  快放的 ghost 账没算，闸上拦着**。
- 字卡：`render_beat_card.py`（数据卡 = 大数字+小标签，转折卡 = 一句短语），
  透明底、品牌配色、走 `inset` 贴角，画面不中断。H2H/里程碑这类单点数据用它浮现。

## 4. 判据清单（「不许 / 必须」逐条，均已有或可落测试）

**文案事实**：
- 排名必须和 `matchup` 一致；种子序号不是排名。
- 纪录/「生涯首冠」类走全称断言双源，证据不足降级为结果句。
- 引用源片的话，落笔前 grep 转写；grep 不到别写。
- 旁白每句 ≤50 字；钩子每行 ≤10 字符（solo）；台头 ≤20 字（半角记 0.5）；
  封面第一句 ≤27 字。
- 旁白解释「为什么变化」，不按记分条把每一局念一遍。

**栏目**：
- 栏目名必须能在 `columns.md` 找到；一个栏目只有一个名字。
- 易逝栏目片子里必须出现「X 月 X 日」；开球之前只做 250+。
- 开球之前封面问题下两行小字，从 `fixture` 结构化字段拼，不手写整行；日期、赛事、
  轮次、两人名字一个不能少，时刻可缺（宁缺不猜）。

**采访**：
- 一份 ASR 不能单独发出去（双模型 ASR + 人工引语交叉，改/增「默认不出片」）。
- 写了 `push.score` 就必须写顶层 `winner`；`winner` 必须是 `matchup` 里的名字。
- 轮次写「1/4 决赛」不写「八强」。

**剪辑**：
- 质检闸一个不撤（一次成型 ≠ 带病发片）；窗口定错宁可超时（发画面对不上旁白的
  片子比晚五分钟糟得多）。
- 比分顶栏第二行 = 赢家 + 完整比分 + 对手，与 `cover.winner/result/matchup` 一致。

**节奏**：
- 赛场之上 ≤30 分钟（正常长度 60-90 秒）；赛后开麦 ≤60 分钟；开球之前开球前 ≥2h；
  网球有故事 ≤24h；历史今天每天 08:37；昨日好球/历史今天晚间 20:00-21:30 错开。
- 每周只改一个变量，样本不足 3 条不下结论。

## 5. 当前接线状态与缺口（无人值守链还要补什么）

**已接线**（`assemble_spec.py` 七步 + 机械对齐）：① flashscore id 反查 → ② stats 块 →
③ 狠数据候选（含 H2H）→ ④ 转折局候选 → ⑤ DeepSeek 文案（facts=狠数据，
background=H2H/近况/排名/中文热点）→ ⑥ 窗口（机械对齐 `--pbp/--scoreboard` 优先，
退回 DeepSeek 读字幕）→ ⑦ 封面实拍（可选）。生产工作流 `match-reel.yml` 的 probe 段
