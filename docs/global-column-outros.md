# 三栏目共用品牌片尾

2026-10-23账号所有者确认替换三个栏目的片尾动画，并在栏目大字前加账号名。三个正式主标题分别是「网球时差 · 赛场之上」「网球时差 · 赛后开麦」「网球时差 · 网球有故事」。这不是中间转场；每条片子在内容收束之后接一次品牌片尾。

## 画面和口播

- 1080×1440、3:4、现有深蓝与原字体，三版同一字号、固定底部品牌位置。
- 使用`assets/logo/brand/account/icon-transparent-1024.png`原图，刚性减速滚入，转角与移动距离匹配，停稳恢复正向；不弹跳拉伸、不绕圈。随后出现账号前缀与栏目名、统一品牌句。
- 背景球场按36×78英尺、单打27英尺宽建模；球网两侧21英尺处为发球线。发球线止于单打边线，中线止于发球线，球网单独虚线表示。
- `outro_page.NARRATION`仍是唯一口播文案出处：**关注网球时差，时差归我，好球归你。** 本次不重新合成，三母版AAC编码数据与旧生产母版一致。
- 0.20–1.92秒logo减速停稳；2.35–3.20秒标题浮现；至少0.9秒完整停留。本次母版247帧/60fps，约4.12秒。片尾长度服从完整口播及最低动效时长，不按8秒demo硬裁或统一加速口播。

## 共享入口

`tennislive.video.column_outro`拥有栏目表、球场几何、统一HTML、确定性逐帧时钟和精确内容缓存。`outro_page.master_for(column)`分别选择`assets/brand/outro_match.mp4`、`outro_interview.mp4`和`outro_story.mp4`。不明确的栏目报错，不能静默改成其他栏目。

- `tools/build_match_reel.py`按spec的column/cover.eyebrow取栏目，包含走该产线的网球有故事；画面片段仍使用占位音轨，由原有旁白时间线接固定口播。
- `tools/build_interview_clip.py`显式选择赛后开麦。
- `video/explainer.py`按登记栏目选择网球有故事。只有已归档、撤销的其他栏目保留原通用片尾；它们不应变成赛场之上。
- 三条线的帧率、采样率、声道数、色彩范围、溶解及混音策略沿用自身合同。60fps母版使用前按目标参数转码；较长旁白使用末帧保持，不截句。

## 重建与复用

在仓库根目录运行：

```bash
PYTHONPATH=src:tools python tools/build_column_outros.py
```

默认从`assets/brand/outro_master.mp4`复制冻结音轨，一次生成三份新画面母版；`--column 赛后开麦`可只重建一版。`--voice-source`可指定已验证的60fps原口播母版。工具校验247帧等原时长、60fps、48kHz双声道及AAC包hash；临时工作放系统临时目录。`assets/brand/column_outros.json`绑定每份母版、统一口播和原音轨指纹。日常出片只转码，不重新启动浏览器或TTS；缺母版时按相同栏目模板现渲，不回退错误栏目。

品牌口播声音不变不等于宣称重新听审；本次验证的是精确编码字节复用。需要改口播时应执行当时有效的全局配音验收，再更新冻结来源。

## 验证与范围

`tests/test_column_outro.py`检查实际母版/编码音轨、三个原生产入口、故事比赛剪辑的栏目选择、标准球场线位、未知栏目及25/30/29.97fps目标流适配。实际渲染另检查主标题边界、原生画面与入场样帧；解码成功不冒充听审。新生成的视频使用新版；历史影片及微信推送记录不变。
