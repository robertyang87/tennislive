# 费德勒这笔投资，走到了足球场

制作中口播底稿。数字与角色以 research.md 的逐项原始来源为准；下面的经营逻辑和未来情景是分析，不是内部合同信息。

费德勒这笔投资，走到了足球场。

九月十八日，昂跑宣布进军足球，姆巴佩成为全球品牌大使，还会参与足球产品的开发测试。一个从跑鞋起家的品牌，为什么从费德勒走到了姆巴佩？这背后，至少有三本不同的账。

第一本，是运动员自己的账。昂跑二〇一〇年成立，费德勒二〇一九年才成为投资者。他不是创始人，也不能因为他持股，就把公司的每个决定都算在他头上。

代言与投资的区别，在于收益从哪里来。代言按合同取得报酬；持股则让资产价值与公司的经营表现联系起来。公司发展得好，股权可能升值；发展不及预期，也要承受损失。股份值多少钱，与卖掉之后实际赚到多少钱，更是两回事。

费德勒还参与了产品合作。二〇二〇年推出的 THE ROGER，先是一双网球风格的日常鞋。之后才有专业网球鞋。商业逻辑就在这里：喜欢一个网球明星的人，并不一定每天都去打网球，却可能每天都穿鞋。

第二本，是个人品牌的账。有一个细节，比猜他赚了多少亿更值得看。昂跑在二〇二四年度报告里披露，THE ROGER 的相关品牌权利来自授权。这意味着，持股、参与产品、授权使用姓名和品牌，是可以分别安排的合作关系。我们没有公开费率，就不能替他算出一笔授权收入。

第三本，才是公司的生意账。进入足球之前，昂跑靠什么赚钱？二〇二六年第二季度，净销售额八点五亿瑞士法郎，鞋类占了约百分之九十二。这个季度结束在六月，不能说成九月签约姆巴佩带来的成绩。

同一季度，约百分之四十六的收入直接来自面向消费者的渠道。这类渠道让品牌更接近顾客，也需要自己承担门店、获客和服务成本。所以卖得贵、有名气，都不等于利润会自动留下来。

再看姆巴佩。官方公布的合作包括产品开发测试；亨利担任足球业务负责人。明星带来的关注，可以缩短一个新品牌被认识的时间。但被认识，只是购买之前的一步。

昂跑准备把喷丝鞋面技术带进足球。这项技术此前用于跑鞋。跑得快，与能不能在足球场上稳定地急停、转向、触球，是不同的产品要求。研发方向已经公布，性能和销量还要等真实产品来回答。

这次扩张可能有两条路。第一条，专业足球装备形成持续需求。第二条，足球带来的新受众，先去购买品牌已有的日常鞋服。两条都可能创造收入，但不能只看集团总销售额，就认定是哪一条成功，更不能把所有增长都归到一名球员身上。

未来真正值得看的是三件事：产品有没有按计划推出；渠道能不能稳定供货；第一批尝鲜的人，会不会继续买。再把这些变化，与库存、费用和利润放在一起核对，才能判断这门生意有没有站稳。

从费德勒到姆巴佩，明星可以把人带到品牌面前。让人掏钱、穿上、再回来买，最后还得靠产品。这才是费德勒这笔投资，走到足球场之后，要继续回答的问题。
