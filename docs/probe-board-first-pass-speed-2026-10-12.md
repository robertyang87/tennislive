## 调用

只有本源画面已经确认转播样式和实际比分框时，才传 `--broadcast-profile`。不按赛事名、URL或猜测选择。若已经有同源原片，可复用输出目录中的 `source.mp4`；缺源时下载行为保持原样。

```bash
PYTHONPATH=src python tools/build_match_reel.py probe \
  --url 'https://www.youtube.com/watch?v=662TF-JlyZY' \
  --outdir output/2026-10-12/reel/paolini-bejlek-wuhan-2026-r1 \
  --from 0 --to 300 \
  --scorebox '90,827,580,982' --broadcast-profile wta
```

`--to 300` 来自本片实际的比赛/采访边界，只适用于这条源和当前编辑范围，不是WTA通用上限。若实际编辑还包括采访，须扫描相应范围并处理其真实几何错误，不能拿比赛部分的通过记录宣称采访也通过。

完整465.65秒原片使用新WTA实际框仍真实报 `WTA board present but native body height cannot be measured`；新路径保留此失败。此次没有将采访背景误检改写成无板或通过，也没有添加推测性质量豁免。

当前新增参数用于原生CLI；现有GitHub表单未增加新输入。调用程序已有同源确认信息时，可将 `given` 与 `profile` 一起传入 `BoardScan` 构造函数。未知源不传 `profile`，继续全部判据扫描；旧调用签名与 `finish()` 补扫继续兼容。

回归仅增加两个必要执行场景：真实解码的WTA自定义框首遍扫描保留全部帧，以及已有probe集成测试中的已确认profile路径。原有未知源、补扫、失败与覆盖检查继续运行。
