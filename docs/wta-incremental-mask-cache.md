# WTA 蒙版局部修订耗时

2026-10-13：整组缓存的输入键包含所有段落。只调整一个回合的窗口，原来会重新扫描全部启用回贴的回合。现在 WTA 整组缓存未命中时，逐段复用经验证的原生 FFV1 蒙版；只扫描输入真正改变的段落，随后按当前段号和路径重新组装完整报告。整组完全未改仍走原有最快的整组命中路径。

每段沿用现有的源片字节、几何/时间窗/帧率、检测器及依赖函数、Python/NumPy、ffmpeg/ffprobe 可执行文件和版本指纹。命中仍检查 manifest、蒙版 SHA256、FFV1 格式、全部帧的时间戳、数量和尺寸；复制后重算 SHA256。检查失败只重扫受影响的段落。发布凭证与最终成片 QC 不进入缓存。

只对原生 WTA 检测器开启分段路径。需要 spec 整体校准的其他比分板继续走原有路径。插入字卡、换段号或调整回合顺序保留回合自身的内容键；换某一条源片仅失效该源的回合。仍用已有 runner 缓存及 dirty 标记，不增加第二套 Actions 缓存。

## 实测

素材：本次郑钦文—斯维托丽娜北京四分之一决赛，源片 SHA256 `da97c5eafb072aa2087e1cee2d893a2c1ea687ac8ef941373e9ccc76553f1d3d`。6 个比分板窗口，共 3,840 帧。只在 benchmark 的内存对象中将第 8 段结束从 232.80 改为 232.76；正式 spec、已发布成片和推送状态均未改动。

| 蒙版步骤 | 实测秒数 |
|---|---:|
| 首次建立整组及分段缓存 | 34.752 |
| 整组完全相同，原有整组命中 | 1.169 |
| 仅一个窗口改变，5 段复用、1 段重扫 | 7.164 |
| 同一修订关闭复用、6 段原生重扫 | 31.284 |

局部修订省 **24.120 秒，约 77%**。5 个未改蒙版字节完全相同；修订后整组的所有解码帧和原生重新生成的整组逐帧相同。缓存约 1.62 MiB，包含两个整组和 7 个单段版本。

首次扫描没有变快，增加了写缓存和验证成本；收益在修订复用。这些数只覆盖蒙版步骤，不能当作端到端出片成绩。

证据：[结构化实测](benchmarks/wta-incremental-mask-cache-2026-10-13.json)、[运行日志](benchmarks/wta-incremental-mask-cache-2026-10-13.log)。相关验证覆盖单窗口修改、字卡插入、重新排序、多源局部变化、单段损坏修复，以及既有完整序列与发布绑定判据。
