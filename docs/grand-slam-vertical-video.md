# 竖屏《网球四大满贯》科普片 · 制作包

一条 **1080×1920 竖屏**、可直接上抖音/小红书/视频号的「网球四大满贯」科普片。包含：

1. 原创解说文案 + 分镜（本文）
2. 一键渲染工具 `tools/build_grand_slam_short.py`
3. 渲染产物 `output/grand-slam-vertical/`（样片、字幕、封面、分镜连拍、发布文案）

> ⚠️ **版权边界（务必先读）**：四大满贯及转播方的官方视频受版权保护，「公开可看」
> 不等于「可搬运」，从 YouTube/抖音等下载官方集锦二次上传属于侵权、且违反平台条款——
> 账号会因此吃版权投诉。本项目**不下载**任何这类视频，脚本也没有下载器。要用到真正的
> 比赛画面，请走授权渠道（向 AO/RG/AELTC/USTA 申请，或购买正版图库/授权集锦），
> 再填入片中的「插入官方授权集锦」占位卡。详见 `README.md` 与 `docs/video-localization.md`。

## 五、渲染

```bash
pip install -e ".[shortvideo]"   # 或 pip install Pillow imageio-ffmpeg
python tools/build_grand_slam_short.py --overwrite
```

产物在 `output/grand-slam-vertical/`：`grand-slam.mp4`、`captions.srt`、`narration.txt`、
`发布文案.txt`（标题/简介/话题/致谢）、`cover.png`、`storyboard.png`、`frames/*.png`。
改文案、时长或配色：编辑 `data/grand_slam_video.json` 后重跑。

## 六、加配音

样片默认静音（片中有字幕）：

1. **剪映 / CapCut**：导入 mp4，用「文本朗读 / AI 配音」读 `narration.txt`，对齐 `captions.srt`。
2. **自备音轨**：`--voiceover 你的配音.mp3 --overwrite`。
3. **edge-tts 自动**：`--tts`（需可访问微软语音服务；本环境被网络策略拦截，故当前样片为静音）。

配乐用无版权/已授权、燃向 BGM，音量压到人声约 -18dB。上平台前把占位镜头换成授权素材、
核一遍画面权利，再发布。
