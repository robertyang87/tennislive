# 竖屏《网球四大满贯》科普片 · 制作包

参考一条抖音横屏科普（大字标题 + 四站赛事 + 底部解说字幕）的结构，重做成一条
**1080×1920 竖屏**、可直接上抖音/小红书/视频号的样片。本包含三部分：

1. 原创解说文案 + 分镜（本文）
2. 一键渲染工具 `tools/build_grand_slam_short.py`
3. 渲染产物 `output/grand-slam-vertical/`（样片、字幕、封面、分镜连拍图）

> ⚠️ **版权边界（与本仓库既有原则一致）**：四大满贯的官方/转播集锦受版权保护，
> “公开可看”不等于“可搬运”，翻译或加字幕也不会自动取得转载权（见
> `README.md` 与 `docs/video-localization.md`）。因此本样片**只使用仓库内可复用
> 授权的静态图**并逐张署名；需要用到官方比赛画面的镜头，一律输出醒目的**占位卡**，
> 由你在拿到授权后替换。脚本没有下载器，不会抓取任何受版权保护的视频。

## 五、渲染

```bash
pip install Pillow imageio-ffmpeg
python tools/build_grand_slam_short.py --overwrite
```

产物在 `output/grand-slam-vertical/`：

| 文件 | 用途 |
|---|---|
| `grand-slam.mp4` | 竖屏样片（含占位卡，可直接预览节奏） |
| `captions.srt` | 逐句字幕/配音脚本时间轴 |
| `narration.txt` | 纯文案（配音用） |
| `cover.png` | 竖屏封面（首帧） |
| `storyboard.png` | 13 格分镜连拍图（审片用） |
| `frames/*.png` | 各镜头单帧（替换/精修用） |

改文案或时长：编辑 `data/grand_slam_video.json` 后重跑即可。

## 六、加配音

样片默认静音（片中有字幕）。三种上配音的方式，任选其一：

1. **剪映 / CapCut**（最省事）：导入 `grand-slam.mp4`，用「文本朗读 / AI 配音」把
   `narration.txt` 逐段读出来，或找真人念，对齐 `captions.srt` 的时间轴。
2. **自备音轨**：`python tools/build_grand_slam_short.py --voiceover 你的配音.mp3 --overwrite`
3. **edge-tts 自动配音**：`--tts`（需能访问微软语音服务；本环境被网络策略拦截，
   故当前样片为静音，脚本已自动回退并保留字幕）。

配乐建议用无版权/已授权 BGM（大气、燃向），音量压到人声 -18dB 左右；上平台前给
占位镜头替换素材、核一遍事实与画面权利即可发布。
