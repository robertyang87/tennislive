# 竖屏《网球四大满贯》科普片 · 制作包

一条 **1080×1920 竖屏**、可直接上抖音/小红书/视频号的「网球四大满贯」科普片，
**介绍赛事本身**（球场、场地、氛围），不聚焦球员，不提金满贯。包含：

1. 原创解说文案 + 分镜（本文）
2. 一键渲染工具 `tools/build_grand_slam_short.py`
3. 渲染产物 `output/grand-slam-vertical/`（样片、字幕、封面、分镜连拍、发布文案）

> ⚠️ **版权边界（务必先读）**：四大满贯及转播方的官方视频受版权保护。
> **不能**从 YouTube、抖音或任何“官方频道 / 公开可看”的页面下载视频二次上传——
> 这属于侵权、违反平台条款，账号会因此吃版权投诉。本项目**不下载**任何这类视频，
> 脚本也没有下载器。片中配图全部来自**精选的可复用授权场馆/球场图**（CC / CC0 / 公有领域）。
> 要用真正的官方比赛画面，请走授权渠道（见第四节），再替换对应镜头。

## 四、要用官方比赛画面时——合法拿片方式（不要扒 YouTube）

“官方频道能看”不等于“允许下载再发”。合法拿到真正比赛画面的三条路：

1. **向赛事方申请媒体/商务授权**：Australian Open / Tennis Australia、Roland-Garros /
   FFT、Wimbledon / AELTC、US Open / USTA，说明用途、平台、时长与地域。
2. **购买正版授权片段**：Getty Images、AP Archive、Reuters 等图库出售可商用的比赛集锦，
   按条许可、附授权凭证。
3. **自有素材或公有领域/CC 授权（且不含 ND）素材**：现场自己拍摄，或明确标注可改编再发布的片段。

拿到后按 `docs/video-localization.md` 逐条留痕：原始链接、权利人、授权名称/凭证、
适用平台与地域期限、是否允许下载/改编/再发布、必须展示的署名；再把对应镜头（尤其澳网占位）
替换进片子。

## 五、渲染

```bash
pip install -e ".[shortvideo]"   # 或 pip install Pillow imageio-ffmpeg
python tools/build_grand_slam_short.py --overwrite
```

产物在 `output/grand-slam-vertical/`：`grand-slam.mp4`、`captions.srt`、`narration.txt`、
`发布文案.txt`、`cover.png`、`storyboard.png`、`frames/*.png`。改文案、时长、配色或配图：
编辑 `data/grand_slam_video.json` 后重跑（镜头类型：`title` / `section` / `photo` /
`triptych` / `collage` / `placeholder`）。

## 六、加配音

样片默认静音（片中有字幕）：

1. **剪映 / CapCut**：导入 mp4，用「文本朗读 / AI 配音」读 `narration.txt`，对齐 `captions.srt`。
2. **自备音轨**：`--voiceover 你的配音.mp3 --overwrite`。
3. **edge-tts 自动**：`--tts`（需可访问微软语音服务；本环境被网络策略拦截，故当前样片为静音）。

配乐用无版权/已授权、燃向 BGM，音量压到人声约 -18dB。发布前把占位镜头换成授权画面、
核一遍画面权利即可。
