## 一、结构：先讲完四代线的来历，再按「线能改变网球的三样」逐样过，最后落到打法

| 段 | 原来 | 改成 |
|---|---|---|
| 钩子 | 四代线／发球上网消失／是线吗 | 不变 |
| 来历 | 羊肠线里插了一句恢复系数；意大利面拍和库仑夹在合成线、聚酯线之间 | 只讲来历：羊肠 → 尼龙 → 显微镜 → 1997 库尔滕、2010 温网聚酯。末尾一句串场：「一根线能改变网球的，只有三样：力量、旋转、磅数。」 |
| ① 力量 | 「那力量呢？」只给结论，不回指恢复系数 | 恢复系数在这里出场并当场讲完：是什么 → 越大球越快 → 实测各种线差别很小 → 所以线没让球变快 |
| ② 旋转 | 库仑一句话、跟转速争论断开 | 库仑在这里出场并讲完：斜刷 → 先滑 → 摩擦拖着转 → 球很快滚起来，摩擦再大也加不了转 → 真正加转的是主线滑开再弹回 → 意大利面拍（放大到极致，被禁）→ 聚酯线（有争议） |
| ③ 磅数 | 已经接回网球 | 补一句机制：球在线上停得更久、出球角度变高 |
| 打法 | 只有「时间对得上」 | 补具体机制：上旋 → 接发球、穿越球急坠，压到上网者脚下 → 发球上网赢分率反而比留在底线低 → 没人上网；再交代分不开 |
| 片尾 | 「线改变了手感、磅数和穿线的规矩」 | 按三样收：没让球变快，让上旋更容易，让磅数掉得更快；打法要和球拍、球一起算 |

## 二、中文旁白新稿（TTS 底稿写汉字；上屏字幕自动换阿拉伯数字）

**钩子**
1. 1874年到今天，网球拍上的线换了四代。
2. 发球上网，却在短短十来年里近乎消失。
3. 是线，改变了网球吗？

**来历**
4. 最早的网球线，是羊的肠衣。
5. 羊肠线贵，又不耐磨、怕潮，于是有了尼龙这样的合成线。
6. 放大来看：天然肠线是一条条牛肠衣绞成的；多股线是很多根尼龙细丝；单丝线是实心的一根。
7. 打久了，线和线交叉的地方会磨出凹槽。
8. 1997年，库尔滕用聚酯线拿下法网；到2010年，温网的男选手都换上了它。
9. 一根线能改变网球的，只有三样：力量、旋转、磅数。

**① 力量——恢复系数**
10. 先看力量。球撞上线床再弹开，弹开和撞进来的速度之比，叫恢复系数，牛顿最早测过。
11. 这个比值越大，线还给球的能量越多，球飞得越快。
12. 可实验室里，各种线都能还回约百分之九十五的能量，换一种线，球速变化很小；
13. 磅数降两成，底线球也只快百分之二到三。
14. 所以，线没有让球变快。

**② 旋转——库仑摩擦定律**
15. 再看旋转。拍面斜着刷过去，球先在线上滑。
16. 摩擦力和压力成正比，这是库仑摩擦定律；正是这股摩擦，拖着球转起来。
17. 可实验发现，几乎每种线的摩擦都够大，球还没离开线就滚起来了；摩擦再大，也加不了转。
18. 真正能加转的，是主线被球拨歪、再弹回来的那一下。
19. 1977年，德国人菲舍尔申请专利：主线和横线不再编织，线能滑开再弹回，转速接近普通球拍的两倍。
20. 1978年，国际网联把它写进规则：禁了。
21. 聚酯线呢？零售商的实验说，它比尼龙多转两成；同行评审的实验，却测不出材料本身的区别。

**③ 磅数——应力松弛**
22. 第三样，磅数。线一拉紧就开始应力松弛，刚穿好就比设定低了约三成。
23. 磅数一掉，球在线上停得更久，出球角度变高，就往界外飞。
24. 聚酯线掉得最快，所以职业球员每换一次新球，就换一支刚穿好的拍子。

**打法**
25. 再看打法：发球上网，1990年代约占四成，2005年后不到一成。
26. 是怎么没的？上旋越来越强，接发球过网就往下坠，正好压到上网者的脚下；穿越球也更快、更准。
27. 上网的人只能在网下截低球。2010到2018年，发球上网的赢分率，反而比留在底线低了五个多百分点。
28. 分析师认为，最大的推手是聚酯线带来的上旋；
29. 可同一时期，球拍和球也都在变，至今没有一项研究，能把线的作用单独算出来。

**片尾**
30. 线没有让球变快；它让上旋更容易，也让磅数掉得更快。打法这笔账，要和球拍、球一起算。
31. 你现在，用的是什么线？

## 五、大字的字体和出场动效（所有者 2026-11-05 追加：「大字字体也很 low，不精致，出现的时候也没特别的动效，比如粒子汇聚之类的效果」）

### 为什么 low（量过的）

| | 现状 | 毛病 |
|---|---|---|
| 中文大字（标题、问句、公式、「禁」） | canvas 写「Noto Sans CJK SC」900 | 机器上思源黑体只装了 Regular／Bold，**900 退成普通 Bold**——最大众的那一款 |
| 清晰度 | 先在 120～150 px 高的 canvas 上画，再当贴图放大到半屏 | 放大后边缘发虚 |
| 3D 立体数字 | `helvetiker_bold`（Three.js 自带的示例字体） | 一眼「默认字体」 |
| 出场 | 透明度 0→1 淡入（「禁」是缩放落下） | 没有设计感 |

### 改法：定一套字体／动效标准，跟 GLOW、MOVE 一样做成全局常量 `TYPE`

1. **字体分三级**（只用 OFL 等可商用免费授权）
   - 一级大字（钩子问句、段落标题、片尾问句）：展示型字体，候选 ① 得意黑（Smiley Sans，仓库已有，科技感斜体）② 思源宋体 Heavy（Noto Serif SC Black，杂志感，要下全量字库）③ 思源黑体 Heavy＋收紧字距＋金属渐变
   - 数据大数字（39.5%、95%、66.8%）：Inter Display Black 或 Barlow Condensed，换掉 helvetiker；做成 3D 挤出＋金属反光扫过
   - 标签小字：保持现在的 Inter／思源黑体，不加动效
2. **清晰度**：改用 SDF 文字渲染（troika-three-text，直接吃 TTF），任何放大倍率边缘都锐利；做不到时 canvas 至少按成片像素 2 倍画
3. **出场动效（只给一级大字和数据大数字，标签不加，免得满屏乱飞）**
   - 粒子汇聚：把字形采样成几千个点，从四周散开的位置沿曲线飞来汇聚成字（约 1 秒，逐字错开），落定后实体字淡入、粒子熄灭；退场时散成粒子飘走
   - 一道光从字面扫过（金属数字）
   - 受两条现有标准约束：粒子用叠加发光，亮度按 `GLOW.k` 压，过 `glow_check.py --pair`；汇聚是连续运动，过 `motion_check.py`，不许闪白
4. **先出样片再定**：做 3 个 4 秒样片（三种字体 × 粒子汇聚，同一句「是线，改变了网球吗？」＋一个数字），你选一个再全片用
5. **落成全局标准**：写进 `docs/vibetennis.md`、`skills/vibetennis-production/SKILL.md`，加静态判据（`scene.js` 不许再出现 `helvetiker`、一级大字必须走 `TYPE`）

### 时间
样片约 1.5 小时（字体接入＋粒子系统＋三个样片）；定了之后全片替换约 1 小时。总时长在第四节基础上加约 2.5 小时，合计 8～9 小时。
