# vibetennis production

完整流程、目录和 TODO 见 [docs/vibetennis.md](../../docs/vibetennis.md)；栏目定位见
[docs/columns.md](../../docs/columns.md) 的「vibetennis」。这里只列开工清单。

## 栏目使命（账号所有者 2026-10-30，每一集都按它验收）

原话：「作为科普视频，内容一定要**精确且详实**，同时**深入浅出**让普通人都能看得懂，同时用**动画特效**呈现效果抓住观众注意力，能**持续看下去**，并能**引爆共鸣和二次传播**，这是这个 vibetennis 的使命和要求」。

六个要求，每个都落成写 spec、渲染前能逐条检查的做法：

| 要求 | 怎么做到 | 写 spec / 渲之前查什么 |
|---|---|---|
| **精确** | 每个上屏数字都读过原文；搜索摘要和二手报道不算核过。数字有冲突、没有一手来源的，就写模糊（「十来台」「一个数量级」）或者不写。**规则、制度、配置类的事实要核到今年**：一篇报道只说明它发表那一年（来路：BBC 2025「温网没有挑战、不放回放」，到温网 2026 已加视频回看——所有者 2026-10-30 问出来的） | `editorial._claims` 每个数字一行：出处、读没读原文；没读的那一行不许上屏 |
| **详实** | 机制要讲到「为什么」那一层，不停在「是什么」；有反证、有局限的必须摆出来（比如电子司线的「平均误差≠每一球」） | `beats` 里至少有一段讲局限或反证 |
| **深入浅出** | 解释一定要**精准清楚**（所有者同日补：「可以不用生活类比，但解释一定要精准清楚」）：术语出现的那一屏当场用画面解释；机制的每一步因果都要交代，不跳步；宁可多一屏，不为好懂把机制简化到失真；字幕一句只讲一件事。类比不强求，用就得在物理上站得住 | 拿字幕念给不看网球的人听：要反问的那句就重写；再问一句：懂行的人看了会不会说「不是这样的」 |
| **动画特效抓注意力** | 开场 5 秒内出一个反直觉的画面或问题；3D 演示的是机制本身，不是装饰 | 镜头提纲里每一段都写清「这一段的视觉事件是什么」，空着的段落删掉或合并 |
| **持续看下去** | 每一段结尾留一个钩子（「那它准在哪？」「可它也出过事」），把观众推进下一段；答案放在中段，不全压到片尾 | 提纲逐段看：这一段末尾，观众有没有理由继续看 |
| **共鸣和二次传播** | 题目必须是观众今天看球还会碰到的事；片中要有一句能单独截出去转发的话或数字；片尾问观众自己的经历 | 选题过「今天的比赛里还在发生吗」；`xhs.txt` 末尾问句问的是观众的经历 |

## 每条理论、每个结论都要接回网球（账号所有者 2026-11-05）

原话：「这个视频有个最大的硬伤就是逻辑混乱，以后不能这么讲了，要把恢复系数和库仑定律对网球的影响要说清楚，即使简单讲也不能不说，因为你说了这些理论又不给人解释和网球的关联，就让人更困惑了。同理发球上网少了因为什么具体原因呢？也要交代下」。

来路：EP07 拍线篇的旁白只**点名**了理论——「前后的速度之比……今天叫它，恢复系数」「球在线上先滑，再被摩擦力带着滚起来，这是库仑摩擦定律」——却没说它管网球的什么。恢复系数在 ① 出场，到 ⑥「那力量呢？」才隐约兑现，而且没回指；库仑那句夹在「被禁」和「库尔滕」之间，跟后面的转速争论断开了。发球上网那段只给了「时间对得上」，没交代**它是怎么变少的**。

| 写到 | 必须同一段里讲完的三步 |
|---|---|
| **一条理论**（恢复系数、库仑摩擦、应力松弛……） | ① 它说的是什么（一句话）→ ② **它管网球的哪一样**（力量／旋转／磅数……），在球和线上是怎么发生的 → ③ 对这个问题它给出什么答案（「所以换线材，球速几乎不变」） |
| **一个现象的变化**（发球上网变少、抢七变多……） | ① 变了多少（数据）→ ② **具体机制**：场上哪一拍、为什么不划算了（有出处的那一条）→ ③ 哪些原因分不开（同期变化） |

- 理论出场的那一屏，就是它兑现的那一屏；不许在 ① 埋名词、隔几段再隐约用上。要跨段，后面那段要明说「回到开头的恢复系数」
- 「时间对得上」不算原因；只给相关、不给机制，等于让观众自己猜
- 自查：把每条理论那句截出去问——**观众听完能不能说出「所以它让网球怎么了」**？说不出就是没讲完

## 所有者口味（2026-10-30，不要用赛场之上的规矩套）

- 16:9 横屏 1920×1080；宏大、有质感、科技/科幻感的 3D 全息场景，不要扁平 2D
- 字幕锚定在被讲的内容旁边（带引线），不压在底部；左上角「网球时差」＋官方图标，片中不出现「VIBE 知识」
- 音效跟画面对齐；时长随内容，约 3 分钟
- 旁白：最早两集无旁白；**中文版自 EP03 起配 TTS 旁白**（edge-tts YunjianNeural +18%，多音字合成换字、字幕保留原字），英文版不配音只留 BGM＋音效（docs/vibetennis.md §8）
- 理论要调研透、每个数有出处；镜头编排先写清楚再渲
- 质量标杆：许先森Ai 抖音片 https://v.douyin.com/ZAuwSjlTKhM/

## 开工清单

1. 选题过「妈妈、高中生、上班族都会说『对』」测试；一个现象，一个反直觉转折，一条有出处的证据链
2. 写 `specs/vibetennis/<slug>.json`（`column`/`cover.eyebrow` = `vibetennis`，`film.canvas` = [1920,1080]，
   `editorial.sources` 不能空，`push.auto` = true）和 `.xhs.txt`（第一行完整问题，正文数字与片子一致，末尾问句，tag ≤5）；
   在 `data/vibetennis_episodes.json` 登记这一集的集数（下一个号）——推送标题是 `EPNN.vibetennis|四字主题`，不写日期
3. 写镜头提纲时先翻 [docs/vibetennis-fx-catalog.md](../../docs/vibetennis-fx-catalog.md)（已有的特效／音色／后期旋钮各适合讲什么，以及调研过的升级工具与授权）
   复制**最近一集**（目前 EP05 `vibetennis-court-speed-2026`）的 `r3d/scene.js`、`overlay.py`、`sfx.py`、`plan.py` 改场景与镜头表；
   渲染脚本不再复制，用共用引擎 `tools/vibetennis/engine/`（`render3d.sh <集目录>` 分块可续渲、`patch.sh <集目录> render|splice` 局部补渲、`serve.sh` 起静态服务）
   - ⭐ **整片渲之前先出审片包**：`python3 tools/vibetennis/engine/review_pack.py <集目录>` 每节、每句字幕各渲静帧拼成总览图（约 120 张，几分钟），
     **发给所有者看过再整片渲**（EP05 的看台缺块、顶棚有孔、地球固定高度都是整段渲完才看出来的，73 个提交、推了三版）
   - 物理／数字类说法（摩擦、恢复系数、评级口径）在审片包之前就过一遍 `papers/<slug>/sources.md`，别等推完再自查（EP05 摩擦段推送后才改稿）
   - ⭐ **光晕标准**（所有者 2026-11-05「所有动效里的光晕都很亮……设定好一个全局标准」）：`scene.js` 抄 `GLOW` 常量（泛光 0.22/0.3/0.93、叠加发光 ×0.5、自发光彩色 ≤0.35／白色 ≤0.15），
     整片渲之前同帧开关泛光各渲一张跑 `tools/vibetennis/glow_check.py --pair`，超标先改再渲。上限和量法见 [docs/vibetennis.md](../../docs/vibetennis.md)「光晕标准」
   - ⭐ **大字标准**（所有者 2026-11-05「大字字体也很 low，不精致……比如粒子汇聚之类的效果」）：`r3d/typefx.js` 软链接 `engine/typefx.js`、`r3d/fonts` 软链接 `assets/fonts`；一级大字用 `bt()`（思源黑体 Black＋粒子汇聚出场），3D 数字用 Inter Display Black（`TTFLoader`，`reversed:true`），不再加载 helvetiker。见 [docs/vibetennis.md](../../docs/vibetennis.md)「大字标准」
   - ⭐ **转场与运镜标准**（所有者 2026-11-05「动画的转场和运镜要做的丝滑且有吸引力」）：切换一律 0.6 s 交叉溶解（自动找切换点），每个镜头缓推 6%＋绕转 3.4°，不许硬切、闪白、静止机位；
     成片跑 `tools/vibetennis/motion_check.py`（相邻帧差 > 12 即超标）。见 docs/vibetennis.md「转场与运镜」
   - 然后 `overlay.py` → `sfx.py`（BGM 要盖满全片）→ `assemble.sh`
4. `r3d/still_cover.js`（EP05；EP01 叫 `still_hd.js`）渲一张竖版原生帧当封面素材；`tools/vibetennis/cover.py` 出**单独一张** 2160×2880 海报（封面**不进视频**，所有者 2026-10-30）
5. `finalize.py`（母片原样拷入，不重编码）→ `qc.py`（全绿才有凭证；有旁白的中文版自动过 `voice_check.py`：配音齐、句与句不重叠、多音字换字或在 narration.json 写 `poly_ok` 认领；背景声 3 秒窗不低于 -28 LUFS）→ 看 `qc_contact.jpg`，最好整片看一遍
6. `upload.py --slug <slug> --date <日期>`（切块代传 Release；改版自动写 replace、英文版自动写 release_tag）→ 等 `vibetennis-upload/<slug>` 分支被删 → `release.py`（video_url ＋ copy.html）→ `push.py --dry-run` 看标题正文 → 提交（不提交 mp4）→ PR
7. 合并即推（CLAUDE.md「片子做完就合并、就推微信」）。**中英两版的 render.json 分两个 PR 依次合**（一趟只发一条）：第一个 PR 里英文版 render.json／凭证保持 main 那份，中文推完再开英文那个；重推先删各自的 `pushed.json`；推完用 `tools/push_link.py --slug <slug>` 取消息网页链接发给所有者
