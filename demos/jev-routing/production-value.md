# Jev 接入：先保住净收益

## 已确认的结论

现有 `collect_oncourt_interviews.py` 的初筛采用本地正则、来源规则和库存标记，
`orchestrate.py` 按比赛状态路由；这两处不是需要替换的昂贵模型调用。
所以此阶段不能声称 Jev 已节省 DeepSeek 费用，也不能用替代本地规则来追求收益。

回放固定提交 ab3a7891d498980c75fc0ebfbf1b89650076a665 的 5,153 条采访库存：

| 分流结果 | 数量 | Jev 调用 |
|---|---:|---:|
| 沿用库存类型 | 4,781 | 0 |
| 保留片尾采访标记 | 308 | 0 |

这是“避免重复分析已分类库存”，不是相对当前系统节省 5,153 次调用。
库存是预筛后的正样本，不能据此推断未来新素材调用比例或准确率。

## 已实现的增量控制

`selective.py` 是独立影子评估入口，使用仓库现有 collector 的规则。
只有既没有可沿用标签、也没有确定规则结果的素材才进入 Jev 候选队列。

- 沿用来源网球闸、逐条黑名单、来源规则及片尾采访标记。
- 本批同内容去重；成功响应缓存 24 小时。
- 缓存键包含实际模型输入、模型版本和完整问题定义；固定 jev-1.13.0，变化自动失效。
- SQLite 原子认领同内容请求，避免多个进程在同一缓存数据库上重复付费。
- 每轮最多 20 次、UTC 每日最多 50 次；尝试失败也占调用预算。
- 401/402/403/429 立即熔断；连续三次错误停止新增请求；不自动重试。
- 网络等待参数 8 秒是 socket 超时，不是端到端硬截止；任务隔离于出片关键路径。
- 失效、缺钥、超时、预算用尽都明确记录为回退状态；`production_action=unchanged`。
- 输出 API 尝试数、缓存命中、规则命中、已知 token 成本、计费未知的请求数。
  相对当前生产节省金额保持 null，直到有真实对照证据。

调用预算基于同一持久 SQLite 数据库。GitHub 缓存丢失/被驱逐或不同分支的缓存隔离会重置
该数据库，不能当成账户级严格账单上限；仍需服务商账单限额。暂不注册定时任务。

## 如何运行

```bash
# 全库存零联网回放
python demos/jev-routing/selective.py --cache /tmp/jev/ledger.sqlite --output /tmp/jev/audit.json
# 把新扫描的候选 JSON 传给 --input；默认离线，仅统计 would_call
python demos/jev-routing/selective.py --input candidates.json --cache /tmp/jev/ledger.sqlite --output /tmp/jev/new.json
# 明确启用实际外部调用时，加 --live；密钥从 TYPESAFE_API_KEY 环境变量读取。
```

输入支持 `{items: {id: item}}` 或 `{items: [item]}`。库存 `kind` 与 `tail_interview`
只接受项目内部数据；这些已有标签不发送给模型。来源未知时仅作候选建议，不自动排除。
新增 `.github/workflows/jev-shadow.yml` 只允许手动运行，默认离线；收集报表和缓存，
不依赖生产渲染任务，不持有写仓库权限，也不触发发布。当前 PR 未合并、未部署该工作流。

## 验证及当前不足

12 项 unittest 通过：已有规则/片尾采访保留、冷/热缓存与重复输入、输入变化失效、
TTL/坏缓存处理、并发认领、单轮与每日预算、限流/超时熔断、缺钥、标签隔离与 HTML 转义。
缓存节省的调用数已用受控响应验证，不能写成真实付费调用实测结果。

追加真实回放选择了一个有公开标题的历史素材，去除已有库存标签，模拟首次发现。
冷调用出现网络失败，服务端是否处理或计费未知；随后自动审批以“外发仓库素材需明确授权”
为由阻止继续。保留 cold-replay.json，未完成真实热缓存验证，不报节省金额。

前一轮 demo 有 18 次成功调用，但模拟足球采访误分仍在；原始记录保留，不能用缓存掩盖。
此版本没有校准模型分类阈值，也没有对新素材形成可靠的质量基准。

## 正式接管的判据

先用连续的新素材建立影子结果，记录错误类别、漏选率、覆盖率、P50/P95 和真实费用。
采用独立、人工核实的标签作为基准；调阈值样本与最终验收样本分开。
仅当某一具体任务证明质量不下降、净成本或延迟改善，才替代该任务已有的模型调用。
若原任务本身是免费规则，必须证明能增加有价值素材发现量，不能只比 API 单价。
所有事实、视觉证据、比分/日期、双打规则、QC 与推送回执继续由既有流程负责。
