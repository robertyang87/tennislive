## FNU 是什么

美国政府系统（USCIS / CBP / 国务院 / SEVIS / SSA）的姓名模型强制分「Given Name」和
「Family Name」两栏。**只有一个名字的人进来，系统就往空的那栏填占位符**：
领事官员盖签证历史上用 `FNU`（First Name Unknown），对应的还有 `LNU`（Last Name Unknown）；
USCIS 自己则填 `No Name Given`。这不是给他一个人的待遇，是一类人的共同遭遇。

## ⚠️ 三个必须注意的口径

1. **「没有名字的球员」是误读。** 意大利几家的标题都写 `il giocatore senza nome`。
   他有完整的藏族名字「尼敦坚赞」，FNU 只是美国表格填不出「名」时的占位符。
2. **他说的「只有姓」和中文资料说的「只有名」是同一件事。** 他在视频里说
   `we don't have a first name, we only have last names`；而中文资料的标准说法是
   藏族**无姓氏、只有名字**（部分人带房名）。两边方向相反，是因为**各自往对方的框架里
   塞的时候塞进了相反的那一格**——而这恰恰就是整条故事的核心。
3. **不止他一个，同一支中国队里就有第二个。**
   - **特日格乐**（蒙古族，呼和浩特）→ 被切成 `Te Rigele` / `Rigele Te`
   - **布云朝克特**（蒙古族，新疆博尔塔拉）→ 全名一个词 `Buyunchaokete`，
     被切成 `Bu` ＋ `Yunchaokete`；**ATP 官网写 `Yunchaokete Bu`，维基条目叫 `Bu Yunchaokete`，
     同一个人在两处姓名顺序相反**
